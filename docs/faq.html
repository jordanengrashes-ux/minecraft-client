Frequently Asked Questions

Answers to the most common questions about Voxel Client.

Yes, completely free. No subscriptions, no premium tiers, no paywalls on any feature.
You need a Microsoft account to play on online servers. For LAN play and offline single-player worlds, you can use offline mode with any username — no account required.
Voxel Client is a launcher — it launches the official Minecraft JAR files downloaded from Mojang's servers. We do not modify the game binary. Mods you install are your own responsibility; only use mods that are permitted on the servers you play on.
Yes. We release builds for Windows (.exe), Linux (.AppImage and .deb), and macOS (.dmg). All platforms are updated automatically.
When you open Voxel Client, it checks GitHub Releases for a newer version. If one is found, it downloads in the background. When Minecraft is not running, it installs automatically and restarts the launcher. You never have to manually download an update.
Go to the Java Mods tab, search for any mod on Modrinth, and toggle it on. The launcher downloads the correct version for your selected Minecraft version and installs any required dependencies automatically.
Most mods require the Fabric mod loader. You can install it with one click from the Java Edition panel. Once installed, enable the Fabric toggle before launching and your mods will load.
Go to the Java Mods tab and switch to the Modpacks section. Search for any Modrinth modpack and toggle it on. The launcher downloads the .mrpack file, extracts all mod JARs, and sets the correct Minecraft and Fabric versions for you.
Yes. Open the Host Server tab, choose your Minecraft version, set your RAM/port/MOTD, and click Start. Enable Dedicated Mode to auto-restart the server if it crashes and keep the PC awake. Enable "Start with Windows" to launch the server automatically at boot.
Offline mode lets you launch Minecraft without a Microsoft account. You pick any username and can play in single-player or on servers that have online-mode disabled. You cannot join servers that require a valid Minecraft account in offline mode.
