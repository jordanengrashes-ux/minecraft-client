Play
Java Edition
Launch any Java version with Microsoft or offline login. Configure RAM, Java version, and Fabric loader in one place.
Bedrock Edition
Launch Minecraft Bedrock directly from the launcher alongside Java — no switching between apps.
Mods
Java Mod Browser
Search Modrinth and install any Java mod with one click. Required dependencies are downloaded automatically.
Modpack Support
Install full Modrinth modpacks instantly. The launcher auto-configures the correct Minecraft and Fabric versions.
PvP Mods
Curated performance and PvP mod packs — Sodium, Lithium, Iris, Entity Culling and more — ready in seconds.
Bedrock Mods & Add-ons
Browse and install Bedrock-compatible mods and add-ons from Modrinth directly inside the launcher.
Resource Packs
Search, download, and manage resource packs from Modrinth. Installed packs update when you change MC version.
Mod Profiles
Save and switch between mod loadouts. Create separate profiles for PvP, survival, and modpacks.
Minecraft Guide (AI)
Built-in AI assistant for crafting recipes, game tips, and Minecraft questions — powered by a live language model.
Social
Skin Manager
Upload and switch skins directly from the launcher. Supports both classic and slim skin variants.
Dedicated Server
Host a 24/7 server from inside the app. Configure RAM, port, MOTD, max players, and auto-restart on crash.
Player Join Alerts
Get a toast notification and the window restores when a player joins your server — even when minimized.
Cosmetics
Equip custom capes visible to other Voxel Client users in-game via a built-in Fabric mod.
Friends & Messaging
Add friends, send messages, and see who is online — all inside the launcher without needing Discord.
Global Chat
Talk with other Voxel Client users across all servers in a built-in global chat channel.
Files Manager
Install worlds and schematics by drag-and-drop. Quick-open your mods, saves, and resource pack folders.
Config
Screenshots Viewer
Browse all your Minecraft screenshots inside the launcher and open them with one click.
Account Manager
Manage multiple Microsoft accounts and switch between them without re-logging in.
Auto Updates
The launcher updates itself silently in the background. You always have the latest version without doing anything.
Start with Windows
Set the launcher to open automatically at boot so your server is always ready when the PC starts.
Customize
Personalize the launcher appearance and settings to match your preferences.
