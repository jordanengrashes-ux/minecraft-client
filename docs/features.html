Everything included

Built for serious players

Every feature Voxel Client ships with — no paywalls, no subscriptions.

Play
Java Edition
Launch any Java version with Microsoft or offline login. Configure RAM, Java version, and Fabric loader in one place.
Bedrock Edition
Launch Minecraft Bedrock directly from the launcher alongside Java — no switching between apps.
Offline Mode
Play offline with a custom username for LAN worlds and practice — no Microsoft account needed.
Memory Control
Set minimum and maximum RAM allocation per launch so Minecraft always has exactly what it needs.
Java Version Picker
Switch between Java 17 and Java 21 builds to match older modpacks or newer Minecraft versions.
Crash Reports
View the latest crash report directly inside the launcher when Minecraft closes unexpectedly.
Mods
Java Mod Browser
Search Modrinth and install any Fabric mod with one toggle. Required dependencies download automatically.
Modpack Support
Install full Modrinth modpacks instantly. Auto-configures the correct Minecraft and Fabric versions.
Modpack Updates
Update installed modpacks to the latest release with one click — no manual re-install needed.
PvP Mods
Curated performance and PvP mods — Sodium, Lithium, Iris, Entity Culling, ImmediatelyFast and more.
Bedrock Mods & Add-ons
Browse and install Bedrock-compatible mods and add-ons directly inside the launcher.
Resource Packs
Search, download, and manage resource packs from Modrinth. Update packs when you change MC version.
Mod Profiles
Save and switch between mod loadouts. Separate profiles for PvP, survival, creative, and modpacks.
Enable / Disable Mods
Toggle individual mods on or off without deleting them. Disabled mods stay installed for quick re-enabling.
Mod Conflict Detection
Conflicting mods are automatically disabled when you enable a mod that is incompatible with them.
Minecraft Guide (AI)
Built-in AI assistant for crafting recipes, game tips, and Minecraft questions — with multi-session history.
Social
Skin Manager
Upload and apply skins directly from the launcher. Supports classic and slim variants with live preview.
Dedicated Server
Host a 24/7 server from inside the app. Configure RAM, port, MOTD, max players, and auto-restart on crash.
Player Join Alerts
Get a notification and window restore when a player joins your server — even when minimized.
Keep Awake
Prevents the PC from sleeping while a server is running so your server stays online 24/7.
Cosmetics
Equip custom capes visible to other Voxel Client users in-game via a built-in Fabric mod.
Friends & Messaging
Add friends, send messages, and see who is online — all inside the launcher.
Global Chat
Talk with other Voxel Client users across all servers in a built-in global chat channel.
Files Manager
Install worlds and schematics by drag-and-drop. Quick-open mods, saves, and resource pack folders.
Config
Screenshots Viewer
Browse all Minecraft screenshots inside the launcher and open them with one click.
Account Manager
Manage multiple Microsoft accounts and switch between them without re-logging in each time.
Auto Updates
The launcher updates itself silently in the background. Always on the latest version automatically.
Start with Windows
Set the launcher to open at boot so your server is always ready when the PC starts.
Customize
Personalize the launcher appearance, backgrounds, and settings to match your setup.
Game Repair
Reinstall corrupted Minecraft files with one click — no manual file deletion needed.
