What you get

Everything included

No paywalls. No subscriptions. Every feature ships free.

Java & Bedrock
Launch Java or Bedrock from the same app. Microsoft and offline login supported. Set RAM and Java version per launch.
Mod Browser
Search Modrinth and install any Fabric mod with one toggle. Required dependencies are downloaded automatically — no manual JAR copying.
Modpack Support
Install full Modrinth modpacks in one click. The launcher auto-sets the correct Minecraft and Fabric versions and keeps modpacks updated.
Performance Mods
Curated one-click mod sets — Sodium, Lithium, Iris, Entity Culling and more — to boost FPS without any manual setup.
Dedicated Server
Run a 24/7 server from inside the app. Configure RAM, port, MOTD, and max players. Auto-restart on crash. Starts with Windows at boot.
Auto Updates
The launcher updates itself silently in the background. You always have the latest version without downloading anything manually.
Friends & Global Chat
Add friends, send direct messages, and join a global chat with other Voxel Client players — all inside the launcher.
Skins, Cosmetics & Files
Upload skins, equip custom capes, install worlds and schematics by drag-and-drop, and browse your screenshots — without leaving the launcher.
